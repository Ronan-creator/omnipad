## Omnipad 1.10.0

**Map every button.** New **Buttons** page: each button (A, B, X, Y, D-pad, L, R, ZL, ZR, Minus, Plus, stick clicks, Home, Capture) can be any Xbox button, nothing at all, or an action: open Playnite (Fullscreen or library), close the current game, screenshot, open Omnipad, press keys (held while you hold the button), or run any program/shortcut/website. Applies straight away; "Reset all to default" puts it back.

**Playnite instead of Steam.**
- Home no longer opens Steam: it used to send the Xbox Guide button, which Steam grabs. Home now opens **Playnite's Fullscreen mode** (or brings it to the front). Change it on the Buttons page; "Xbox Guide button" is still there if you want it.
- Hold Home now opens Playnite too, and the Capture button takes a Windows (Game Bar) screenshot instead of Steam's F12.
- Hold-to-run shortcuts gained "Playnite: open Fullscreen mode", "Playnite: open library" and "Close the current game".
